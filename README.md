# ballardfremontdispatch.com

Static landing site for the Ballard & Fremont Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py ballardfremont` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `ballardfremont-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
